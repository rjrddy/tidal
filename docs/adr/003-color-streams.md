# A color-band traffic lab

Outside visual research: MoMA's Josef Albers artist overview and color-combination teaching material:
https://www.moma.org/artists/97-josef-albers
https://www.moma.org/momaorg/shared/pdfs/docs/learn/mondays/Josef-Albers-Color-combinations.pdf

Tidal uses original nested colored bands, large heavy sans type, vermilion actions, muted pink/blue/ochre comparison streams and an off-white field. The sources informed interacting color and repeated bands; no artwork, branding, fonts or page layout was copied. All art is original CSS/SVG, with no external assets or scripts. It deliberately differs from Atlas's nautical map and the other existing project designs.

Every decorative hero band is aria-hidden. Actual chart areas come from completed request windows, with a numeric table for inspection. Recorded replay, on-demand replay and live HTTP have explicit separate labels. Overflowing tables/tapes scroll inside their own containers; focus rings and input labels support keyboard access.
