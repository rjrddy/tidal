# Tidal migration

The approved audit selected no direct source transfer from an older small repository for Tidal. Cache policies, count-min admission, shadow selection, refresh/invalidation fencing, HTTP origin/proxy and replay are new work. Test/build workflow patterns follow the existing independent projects, without a runtime dependency on their directories.

Web12 is a newly imported licensed public key-order trace from cache2k-benchmark; provenance and CC BY attribution live in data/ and docs/results/trace-provenance.json. It is not a measurement copied from another implementation.

Cinder remains unchanged. Its existing independent checks do not prove a Tidal integration. A separate Cinder proposal documents the requirements; the current cache uses its own in-process metadata and values. No old directory or remote repository was removed.
